# 👤 Profile Card UI

Um projeto moderno e responsivo de **Cartão de Perfil Social**, desenvolvido com foco em design limpo, organização visual e experiência do usuário.  
Ideal para estudos de **HTML5** e **CSS3**, além de servir como base para portfólios, páginas de apresentação pessoal ou componentes de interfaces modernas.

---

## 📸 Preview do Projeto

Interface minimalista contendo:

- Foto de perfil destacada
- Nome e ocupação do usuário
- Links para redes sociais
- Botões de interação
- Estatísticas de engajamento
- Layout centralizado e elegante

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Visual moderno e sofisticado
- Paleta de cores suave e profissional
- Ícones sociais integrados
- Estrutura organizada e intuitiva
- Componentes reutilizáveis
- Sombreamento suave e bordas arredondadas
